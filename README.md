# Резак

[English](README.en.md)

Резак — приложение для Windows, которое разбивает изображение на листы A4 или A3 для печати плаката заданного физического размера. Вы задаёте ширину и высоту готового плаката, а программа рассчитывает количество листов. Незанятая часть последнего ряда и последнего столбца остаётся белой.

## Запуск

Если у вас есть готовая сборка для Windows 10/11 x64, откройте `Rezak.exe` рядом с папкой `Data/`. Сборка включает среду .NET. При переносе на другой компьютер копируйте всю папку с программой.

Если вы скачали исходный код, сначала [соберите приложение](#сборка-из-исходников). Затем откройте `dist\Rezak.exe` или запустите `Start_Windows.bat` из корня проекта.

## Как напечатать плакат

1. Откройте изображение в формате PNG, JPEG, BMP, TIFF или WebP либо перетащите один файл в окно. Поддержка WebP зависит от установленных в Windows кодеков.
2. Введите ширину и высоту готового плаката в сантиметрах или миллиметрах. При смене единиц программа пересчитает введённые размеры, поля и перекрытие.
3. Выберите формат бумаги (A4 или A3), ориентацию, поля и перекрытие. Проверьте раскладку и число листов в предпросмотре.
4. Сохраните PDF или PNG либо отправьте плакат на принтер из программы. Для экспорта доступны 150, 200 и 300 DPI.
5. При печати выберите тот же формат и ориентацию бумаги, установите масштаб **100% / Фактический размер** и отключите подгонку под страницу. Выбранные поля должны быть не меньше аппаратных полей принтера. Перед печатью всего плаката можно измерить пробный лист линейкой.
6. Соберите плакат по схеме. Если задано перекрытие, совместите повторяющиеся полосы соседних листов. При нулевом перекрытии обрежьте поля по стыкам и соедините фрагменты встык.

Размер готового плаката считается по изображению без полей и повторяющихся полос. Резкость большого плаката зависит от разрешения исходника. Параметры раскладки и экспорта сохраняются при закрытии приложения. В окне «Настройки» их можно экспортировать в JSON и импортировать обратно.

## Что сохраняет экспорт

- **PNG** сохраняет полные листы с полями в `Pages/1.png`, `Pages/2.png` и далее. Листы идут слева направо и сверху вниз. На них нет меток обрезки и подписей. Отдельно сохраняются `Assembly_Map.png` с номерами листов и `Assembly_Readme.txt` с параметрами и инструкцией по сборке.
- **PDF** содержит схему сборки на первой странице и фрагменты плаката со второй. Для сборки печатайте страницы со второй. Для PDF и прямой печати можно включить метки обрезки при полях от 3 мм.

## Как рассчитывается раскладка

A4 имеет размер 210 × 297 мм, A3 — 297 × 420 мм. По каждой оси доступная область равна размеру листа за вычетом двух полей. Шаг сетки равен доступной области за вычетом перекрытия. Линии в предпросмотре показывают шаг сетки. При ненулевом перекрытии соседние листы содержат общую полосу изображения.

Например, для плаката **100 × 50 см** на альбомных листах A4 с полями 8 мм и без перекрытия доступная область составляет **281 × 194 мм**. Получается 4 столбца и 3 ряда, всего **12 листов**. На правом краю ширина изображения составляет 157 мм, на нижнем высота составляет 112 мм.

## Сборка из исходников

Для сборки на Windows установите **.NET 8 SDK** или более новый .NET SDK. Для готового комплекта Windows x64 также нужны Visual Studio или Visual Studio Build Tools с рабочей нагрузкой «Разработка классических приложений на C++». Сторонние NuGet-пакеты не требуются.

Запустите [`Build_EXE_Windows.bat`](Build_EXE_Windows.bat) из корня проекта. После успешной сборки скрипт заменит папку `dist/`, в которой будут запускатель `Rezak.exe` и файлы приложения в `Data/`. Промежуточные файлы сборки сохраняются в `artifacts/`.

Для запуска в режиме разработки откройте [`PosterMaster.sln`](PosterMaster.sln) в Rider или Visual Studio либо выполните из корня проекта команду:

```powershell
dotnet run --project src/PosterMaster/PosterMaster.csproj
```

Код приложения на C# и WPF находится в [`src/PosterMaster/`](src/PosterMaster/), код запускателя на C — в [`src/PosterMaster.Launcher/`](src/PosterMaster.Launcher/).
