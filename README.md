# Резак — C# / WPF

Настольное Windows-приложение для разделения изображения на страницы A4/A3 **по заданному физическому размеру готового плаката**. В отличие от способа «растянуть на N листов», приложение сохраняет указанный размер: крайние справа и снизу листы могут быть заполнены частично.

## Требования

- Windows 10/11 (x64).
- Для сборки приложения из исходников нужен **.NET 8 SDK** или более новый SDK.
- Для сборки готового комплекта через `Build_EXE_Windows.bat` также нужны Visual Studio или Build Tools с компонентом «Разработка классических приложений на C++».
- Готовая сборка включает среду .NET и запускается без её отдельной установки.
- Нет сторонних NuGet-зависимостей, PDF генерируется встроенным кодом.

## Структура проекта

- `src/PosterMaster/` — исходники C#, разметка WPF и файл проекта.
- `src/PosterMaster.Launcher/` — исходник Windows-запускателя.
- `dist/` — запускатель `Rezak.exe` и папка `Data/` с приложением, библиотеками и языковыми ресурсами.
- `artifacts/` — служебные файлы и промежуточные результаты сборки.
- `PosterMaster.sln` — решение для открытия в Rider.

## Запуск

1. Распаковать архив в обычную папку, желательно с коротким путём (например `C:\PosterMaster`).
2. Открыть `dist\Rezak.exe` или дважды щёлкнуть `Start_Windows.bat` в корне проекта.
3. Открыть PNG/JPEG/BMP/TIFF/WebP кнопкой или перетащить один файл в окно. Поддержка WebP зависит от установленных в Windows графических кодеков.
4. Выбрать сантиметры или миллиметры и ввести **ширину и высоту готового плаката**. При переключении единиц уже введённые размеры, поля и перекрытие пересчитываются.
5. Выбрать A4/A3, нажать кнопку с горизонтальным или вертикальным листом и задать поля и перекрытие.
6. Использовать предпросмотр и экспорт: PNG-фрагменты + `Assembly_Map.png`, PDF или печать напрямую.

## Сборка EXE

Запустите `Build_EXE_Windows.bat`, чтобы пересобрать автономную версию для Windows x64. Скрипт заменяет папку `dist` после успешной сборки. Для переноса на другой компьютер копируйте `dist` целиком и запускайте верхний `Rezak.exe`.

Для запуска из исходников откройте `PosterMaster.sln` в Rider или выполните из корня проекта:

```powershell
dotnet run --project src/PosterMaster/PosterMaster.csproj
```

## Геометрия

- A4: 210 × 297 мм. A3: 297 × 420 мм.
- На каждом листе печатается содержимое не шире `ширина бумаги − 2 × поле`, и не выше `высота бумаги − 2 × поле`.
- Шаг сетки = печатная область − перекрытие.
- Для последней колонки/строки ширина/высота картинки ограничена оставшейся физической частью плаката. Незанятая часть листа остаётся белой при печати и экспорте в PNG и PDF.
- Никакого автоматического заполнения каждого листа или дополнительного растягивания изображения нет.
- Перекрытие = повтор изображения, предназначенный для наложения листов при сборке. При перекрытии нельзя просто приклеивать соседние края встык.
- Для точного физического размера печатать в **100% / Actual size**, отключить `Fit to page` / «Подогнать под лист». Выбранное поле должно быть не меньше физически непечатаемых областей конкретного принтера.
- Размеры готового плаката указаны по самой картинке; белые поля и дублирующиеся области перекрытия не входят в размер плаката.
- На правых/нижних листах метки обрезки отмечают границу реального изображённого фрагмента.

## Пример

Плакат 100 × 50 см, лист A4 альбомный (297 × 210 мм), поля 8 мм, перекрытие 0:
- Рабочий размер одного листа: 281 × 194 мм.
- Колонки: 4, ряды: 3, итого **12 листов**.
- Последний столбец: 157 мм изображения (а не 281 мм).
- Последняя строка: 112 мм изображения (а не 194 мм).

**Примечание:** в сетке без перекрытия каждая страница содержит только один неповторяющийся прямоугольник; при печати могут понадобиться обрезка полей и соединение по краям. При перекрытии удобнее совмещать листы с небольшим нахлёстом (например, 5 мм).

## Выходные файлы

- `Pages/1.png`, `Pages/2.png` и т. д. — полные листы A4/A3 с выбранными полями. Метки обрезки и подписи в PNG отключены. При печати выбирайте масштаб 100%, чтобы сохранить размер плаката.
- `Assembly_Map.png` — схема сборки с теми же номерами, слева направо и сверху вниз.
- `Assembly_Readme.txt`: параметры раскладки и инструкция.
- PDF — схема раскроя на первой странице, затем пронумерованные фрагменты на листах A3/A4 в выбранном DPI.

## Известные особенности

- Принтеры различаются аппаратными полями и масштабированием в драйверах. Перед серией распечатайте и измерьте тестовый лист по линейке.
- У очень маленьких исходных изображений резкость на большом плакате будет ограничена исходным разрешением.
- Предпросмотр схемы показывает **границы продвижения сетки**; при перекрытии фактические листы содержат повторяющиеся полосы, указанные в параметре «Перекрытие».
